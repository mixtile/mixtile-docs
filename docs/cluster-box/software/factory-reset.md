# Resetting to Factory Settings

Cluster Box’s new Controller Board includes a factory reset feature for restoring the default firmware, even if the updates fail or the system won’t boot.

## Resetting steps

1.  Unplug the power cable of Cluster Box.
2.  Press and hold the **ON/OFF** button, plug the power cable, and hold the button for over 5 seconds before releasing it.
3.  Wait about 2-3 minutes for the reset to complete. Once the reset is done, Cluster Box will restart automatically with its original firmware.

## Monitoring the reset process

You can watch the LED indicator for the reset process:

- Flashes extremely frequently: resetting to factory settings

  ![The ON/OFF button on the Cluster Box front panel, with its blue LED flashing rapidly](/img/docs/resetting-to-factory-settings/43a5f4d3d32b.webp)

- Flashes frequently: restarting

  ![The ON/OFF button on the Cluster Box front panel, with its blue LED blinking slowly](/img/docs/resetting-to-factory-settings/16d92805b0f3.webp)

- Stays on: started normally

  ![The ON/OFF button on the Cluster Box front panel, with its blue LED lit continuously](/img/docs/resetting-to-factory-settings/f46a626abae1.webp)
