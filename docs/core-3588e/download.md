# Downloads

## Mixtile OS

Mixtile OS is the official operating system for Core 3588E. The links below download images from the [current Mixtile OS release](https://github.com/mixtile-rockchip/mixtile-os/releases/latest). Pick one image:

- **Edition.** Choose **Desktop** to use the module with a monitor, keyboard and mouse. Choose **Server** to use it without a monitor, over SSH or the serial console.
- **Distribution.** All four give the same hardware support on Core 3588E. Choose the one your software is packaged for. If you are following another guide, use the distribution that guide was written for.

| Distribution | Desktop | Server |
| --- | --- | --- |
| Ubuntu 24.04 LTS | [Download](https://github.com/mixtile-rockchip/mixtile-os/releases/latest/download/ubuntu-24.04-desktop-arm64-mixtile-core3588e.img.xz) | [Download](https://github.com/mixtile-rockchip/mixtile-os/releases/latest/download/ubuntu-24.04-server-arm64-mixtile-core3588e.img.xz) |
| Ubuntu 26.04 LTS | [Download](https://github.com/mixtile-rockchip/mixtile-os/releases/latest/download/ubuntu-26.04-desktop-arm64-mixtile-core3588e.img.xz) | [Download](https://github.com/mixtile-rockchip/mixtile-os/releases/latest/download/ubuntu-26.04-server-arm64-mixtile-core3588e.img.xz) |
| Debian 12 | [Download](https://github.com/mixtile-rockchip/mixtile-os/releases/latest/download/debian-12-desktop-arm64-mixtile-core3588e.img.xz) | [Download](https://github.com/mixtile-rockchip/mixtile-os/releases/latest/download/debian-12-server-arm64-mixtile-core3588e.img.xz) |

## Flashing Tool

Rockchip Flash Tool writes an image to the module over USB. The links below download it from the [latest release](https://github.com/mixtile-rockchip/rockchip-flash-tool/releases/latest):

| Operating system | Rockchip Flash Tool |
| --- | --- |
| Windows 10 or 11 | [Download](https://github.com/mixtile-rockchip/rockchip-flash-tool/releases/latest/download/Rockchip-Flash-Tool-windows-x64.zip) |
| macOS 13 or later | [Download](https://github.com/mixtile-rockchip/rockchip-flash-tool/releases/latest/download/Rockchip-Flash-Tool-macOS-universal.dmg) |
| Linux x86_64 | [Download](https://github.com/mixtile-rockchip/rockchip-flash-tool/releases/latest/download/Rockchip-Flash-Tool-linux-x86_64.AppImage) |

For instructions, see [Flashing an OS Image](/core-3588e/getting-started/install-os).
