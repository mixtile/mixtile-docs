# U.2

The U.2 edge connector on Blade 3 carries four lanes of PCIe 3.0, a SATA 3.0 channel and a 12 V power input.

It is used by:

- the M.2 NVMe adapter included with the [Blade 3 Case](/blade-3/accessories#blade-3-case)
- the [Blade 3 Breakout Board](/blade-3/accessories#blade-3-breakout-board), which brings out 12 V power input, PCIe for clustering, and SATA

For powering the board through this connector, see [Power Supply](/blade-3/getting-started/power-supply).

After you install an NVMe SSD, run `lsblk` on Blade 3 and check that it lists an `nvme0n1` disk.

## Specifications

- 68-pin U.2 edge connector
- PCIe 3.0 x4
- SATA 3.0
- 12 V power input, 12 V at 3 A, on pins P13 to P15
