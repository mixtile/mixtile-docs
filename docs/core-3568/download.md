### Development Documents

Each package contains the data sheet, the pin info spreadsheet, the schematic symbol library (OrCAD 16.6), the PCB footprint library (Allegro 16.6), the 3D model (STP), and RKDevTool with its driver installer.

- [Core 3568 development documents V1.3](https://downloads.mixtile.com/core3568/file/Developement_Documents_Core3568_v1.3_240604.zip) (ZIP, 14 MB)
- [Core 3568J development documents V1.1](https://downloads.mixtile.com/edge2/Developement_Documents_Core3568J_v1.1_220606.zip) (ZIP, 22 MB)

The Mixtile Edge 2 main board is a carrier board for Core 3568. Its schematic and components placement map are on the [Edge 2 downloads page](/edge-2/download).
