# Specifications

:::info
内容翻译同步中，以下为英文原文。
:::

| Item | Specification |
| --- | --- |
| CPU | Quad-core Cortex-A55 SoC Processor RK3568 up to 2.0 GHz |
| NPU | Up to 0.8 Tops |
| Memory | 2 GB or 4 GB LPDDR4 SDRAM in the two default configurations; the Core 3568 module supports 2 GB to 8 GB |
| Storage | 16 GB or 32 GB eMMC in the two default configurations; the Core 3568 module supports 16 GB to 256 GB |
| Display | 1x HDMI2.0, 1x eDP, 2x MIPI-DSI, and 1x MIPI-CSI |
| Video encoder | 1080P100 H.264/H.265 video encoder |
| Video decoder | 4KP60 H.265/H.264/VP9 video decoder |
| Network | 10/100/1000 BASE-T |
| Wi-Fi | Wi-Fi 6 802.11ax |
| Bluetooth | Dual-Mode Bluetooth 5.0 |
| Module support | 4G, 5G, LoRa, and Zigbee modules |
| Storage expansion | 1x MicroSD 3.0 flash expansion socket / 1x M.2 Socket: PCIe 3.0, USB 3.0, SIM socket |
| Audio interfaces | 3x PDM, 1x SPDIF, 1x Speaker, 1x IR, and 4x ADC |
| Other interfaces | 1x RS485, 1x CAN, 1x I2C, and 2x UART |
| Interface expansion | 1 x U.2 Socket: SATA/PCIe, SATA, RGMII/SPI/I2S, USB2.0 |
| Other expansion | 1x Mini-PCIe Socket: USB2.0, SIM Socket |
| USB | 3x USB 2.0/3.0 ports up to 5 Gbps data rates |
| Power supply | Type-C PD3.0 Power input (Max 3A @ 20V) / 12 V DC/SATA Power input (Max 3A) |
| Power management | Real Time Clock with Battery Backup |
| Operating temperature | 0 to +80°C |
